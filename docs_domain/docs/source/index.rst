Sales report
============

Утилита читает файл продаж магазина и строит сводный отчёт.

Документация собрана из файлов в разных форматах: эта страница — reStructuredText,
описание предметной области и спецификация — Markdown, справочник API
генерируется из docstring-ов кода.
