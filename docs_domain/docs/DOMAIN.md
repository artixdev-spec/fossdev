# Предметная область: учёт продаж магазина

## Контекст

Небольшой магазин в конце дня выгружает продажи в текстовый файл.
Нужна утилита, которая читает этот файл и строит сводный отчёт.

## Сущности

| Сущность          | Описание                                                     |
|-------------------|--------------------------------------------------------------|
| Продажа (запись)  | Одна строка файла: товар, категория, цена за единицу, количество |
| Категория         | Группа товаров: напитки, выпечка, фрукты и т.п.              |
| Сумма позиции     | Цена за единицу × количество                                 |
| Итоговая сумма    | Сумма всех корректных позиций, возможно со скидкой           |
| Отчёт             | Текст: заголовок, суммы по категориям, итог                  |

## Что делает система

1. Читает файл продаж и отбрасывает некорректные строки.
2. Считает итог по всем продажам (с учётом скидки).
3. Находит крупные продажи — сумма позиции не меньше заданного порога.
4. Группирует суммы по категориям.
5. Формирует текстовый отчёт.

## Вне рамок

Налоги, возвраты, несколько валют, учёт клиентов и склада, интеграции
с внешними системами.
