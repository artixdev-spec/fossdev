# Спецификация модуля `sales`

## Формат входных данных

Текстовый файл в UTF-8, одна продажа на строку, поля через запятую:

```
<товар>,<категория>,<цена за единицу>,<количество>
```

Пример:

```
Кофе,напитки,150.5,2
Круассан,выпечка,90,3
```

## Правила валидации

- В строке ровно 4 поля.
- Цена — число, не меньше 0.
- Количество — целое число, больше 0.
- Пустые строки пропускаются.
- Некорректная строка пропускается, обработка файла продолжается.

## Функции

| Функция | Вход | Результат |
|---|---|---|
| `read_sales(path)` | путь к файлу | список корректных записей `Sale` |
| `total_amount(sales, discount_percent=0)` | записи, скидка 0–100 % | итоговая сумма со скидкой; скидка вне 0–100 → `ValueError` |
| `filter_by_threshold(sales, threshold)` | записи, порог | записи, у которых сумма позиции ≥ порога |
| `totals_by_category(sales)` | записи | словарь `категория → сумма` |
| `build_report(sales)` | записи | текст отчёта: заголовок, категории по алфавиту, итог |

Все суммы округляются до копеек (2 знака).
