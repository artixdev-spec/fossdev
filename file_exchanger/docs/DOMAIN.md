# Сервис передачи файлов (File Transfer Service)

## Назначение

Отправитель загружает файл и указывает email получателя. Сервис сохраняет файл
в облачном хранилище и отправляет получателю письмо со ссылкой. Получатель
скачивает файл по ссылке.

## Участники

| Участник            | Роль                                                                 |
|---------------------|----------------------------------------------------------------------|
| Sender              | Загружает файл, указывает email получателя                           |
| Recepient           | Получает уведомление, скачивает файл                                 |
| Cloud (FileStorage) | Внешнее хранилище: хранит файлы, выдаёт их по ID, сообщает о нехватке места |
| Email Service       | Внешний сервис отправки писем                                        |

## Потоки данных (контекстная диаграмма — `context.drawio`)

- Sender → сервис: файл и email получателя.
- Сервис → хранилище: файл; хранилище → сервис: ID файла.
- Хранилище → сервис: сигнал о заполнении места (Space Usage Alarm).
- Сервис → Email Service: запрос на уведомление; Email Service → Recepient: письмо.
- Recepient → сервис: запрос файла по ссылке.

## Варианты использования (`use_cases.drawio`)

1. **Upload file** — отправитель загружает файл.
   Включает: *Specify recipient email*, *Access file storage*, *Notify recipient*.
2. **Notify recipient** — письмо со ссылкой через Email Service.
3. **Download file** — получатель скачивает файл по ссылке.
   Включает: *Access file storage*.
4. **Report space usage alarm** — расширяет *Access file storage*:
   срабатывает, когда в хранилище заканчивается место.

## Вне рамок

Регистрация и авторизация пользователей, шифрование файлов, срок хранения
и автоудаление, ограничения на размер файла.
