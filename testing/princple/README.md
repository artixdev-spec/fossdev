# Автоматизация Python-проекта с использованием Make

## Введение

Цель данного проекта — продемонстрировать, как с помощью Make можно организовать
воспроизводимый процесс разработки Python-приложения.

Make выступает в роли единой точки входа для:
- создания окружения
- установки зависимостей
- запуска тестов
- проверки типов
- проверки качества кода

## Структура проекта
testing/princple/
├── src/ # исходный код
├── tests/ # тесты
├── Makefile # автоматизация
├── requirements.txt
└── README.md

## Работа с окружением

Проект использует локальное виртуальное окружение `.venv`, расположенное в корне репозитория.

Важно: в Makefile не используется `source venv/bin/activate`, так как Make выполняет каждую команду в отдельном shell.

Вместо этого используются прямые вызовы:
.venv/bin/python
.venv/bin/pip

Это гарантирует корректное использование окружения проекта.
